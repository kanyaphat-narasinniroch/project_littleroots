พืชแนะนำ

กะเพรา / Holy basil

Ocimum tenuiflorum

ไม้พุ่มหอมที่เป็นพระเอกของเมนูผัดกะเพรา

ใบไม้พุ่ม
อ่านข้อมูล

มะละกอ / Papaya

Carica papaya

ผลไม้และผักที่กินได้ทั้งแบบดิบและสุก

ผลไม้ล้มลุก
อ่านข้อมูล

ยางพารา / Para rubber tree

Hevea brasiliensis

ต้นไม้ที่ให้น้ำยางสำหรับทำผลิตภัณฑ์ยางหลากชนิด

น้ำยางไม้ยืนต้น
อ่านข้อมูล

ราชพฤกษ์ / Golden shower tree

Cassia fistula

ดอกไม้ประจำชาติไทย ช่อดอกสีเหลืองทองห้อยระย้า

ดอกไม้ยืนต้น
อ่านข้อมูล
