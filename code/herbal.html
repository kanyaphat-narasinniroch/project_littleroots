เรียงลำดับ:
🌿 ผักริมรั้ว

ชะอม

Cha-om (Acacia pennata)

ยอดอ่อนมีรสมันและกลิ่นฉุนเฉพาะตัว ยอดนิยมนำไปทอดไข่ชะอมคู่กับน้ำพริกกะปิ

รสมันฉุน ส่วนที่กิน: ยอด/ใบอ่อน
⭐ วิตามินเอสูง อ่านข้อมูล / View →
🌱 ผักป่าธรรมชาติ

ผักหวานป่า

Pak-Waan (Melientha suavis)

ราชินีผักป่ารสหวานตามธรรมชาติ กรอบอร่อย เหมาะสำหรับแกงเลียงและต้มจืดหมูสับ

รสหวานกรอบ ส่วนที่กิน: ยอดอ่อน
⭐ แคลเซียมสูง อ่านข้อมูล / View →
🥬 ผักริมรั้ว

ตำลึง

Ivy Gourd (Coccinia grandis)

ไม้เลื้อยริมรั้วดูแลง่าย รสจืดเย็น ธาตุอาหารสูง ช่วยบำรุงสายตาและระบบขับถ่าย

รสจืดเย็น ส่วนที่กิน: ใบ/ยอด
⭐ บำรุงสายตา อ่านข้อมูล / View →
🥭 ผลไม้พื้นเมือง

มะละกอ

Papaya (Carica papaya)

ผลดิบทำส้มตำกรุบกรอบ ผลสุกเนื้อสีส้มรสหวานฉ่ำ เอนไซม์ปาเปนช่วยย่อยอาหารได้ดีเยี่ยม

รสหวานฉ่ำ ส่วนที่กิน: ผลดิบ/ผลสุก
⭐ วิตามินเอ & ซี อ่านข้อมูล / View →
🍇 ผลไม้พื้นเมือง

มังคุด

Mangosteen (Garcinia mangostana)

ราชินีแห่งผลไม้ไทย เนื้อขาวบริสุทธิ์ รสชาติหวานอมเปรี้ยว สดชื่นคลายร้อน

รสเปรี้ยวหวาน ส่วนที่กิน: เนื้อผล
⭐ สารต้านอนุมูลอิสระ อ่านข้อมูล / View →
🍈 ผลไม้ & ไม้มงคล

ขนุน

Jackfruit (Artocarpus heterophyllus)

ยวงสีเหลืองทองรสหวานหอมกรอบ ส่วนผลอ่อนนำมาปรุงแกงคั่วหรือตำขนุนรสเลิศ

รสหวานแน่น ส่วนที่กิน: ยวงผล/เมล็ด
⭐ พลังงานธรรมชาติ อ่านข้อมูล / View →
🥒 ผักผลเปรี้ยว

ตะลิงปลิง

Bilimbi (Averrhoa bilimbi)

ผลไม้รสเปรี้ยวจี๊ดถึงใจ นิยมนำมาใส่ต้มยำ ยำ หรือทานคู่กับกะปิหวานเติมความสดชื่น

รสเปรี้ยวจี๊ด ส่วนที่กิน: ผลสด
⭐ วิตามินซีเข้มข้น อ่านข้อมูล / View →
🌾 ผักน้ำสะอาด

ผักกูด

Paco Fern (Diplazium esculentum)

เฟิร์นทานได้ที่เจริญเติบโตเฉพาะแหล่งน้ำสะอาด ยอดม้วนกรอบ เหมาะทำยำผักกูดกุ้งสด

รสหวานกรอบ ส่วนที่กิน: ยอดอ่อน
⭐ ดัชนีน้ำบริสุทธิ์ อ่านข้อมูล / View →
🧂 เครื่องเทศพื้นบ้าน

ข่าลิง / มะแขว่น

Northern Pepper (Zanthoxylum limonella)

เครื่องเทศล้านนาเอกลักษณ์ กลิ่นหอมซ่าเป็นเอกลักษณ์ นิยมใส่ในลาบคั่วและแกงแค

กลิ่นหอมซ่า ส่วนที่กิน: เมล็ด/ผลแห้ง
⭐ ขับลมในกระเพาะ อ่านข้อมูล / View →
🍋 เครื่องแกงไทย

มะกรูด

Kaffir Lime (Citrus hystrix)

ผิวมะกรูดและใบหอมฉุน ขาดไม่ได้ในต้มยำและพริกแกง มีน้ำมันหอมระเหยช่วยให้ผ่อนคลาย

หอมระเหยเปรี้ยว ส่วนที่กิน: ใบ/ผิวผล
⭐ สารไซตรอนเนลลัล อ่านข้อมูล / View →
☘️ ผักแนมสมุนไพร

ผักแพว

Vietnamese Coriander (Persicaria odorata)

ผักพื้นบ้านกลิ่นหอมฉุน รสเผ็ดปร่าเล็กน้อย นิยมกินแนมกับลาบ น้ำตก และข้าวยำปักษ์ใต้

รสเผ็ดปร่า ส่วนที่กิน: ยอด/ใบ
⭐ บำรุงการไหลเวียน อ่านข้อมูล / View →
🪷 พืชน้ำกินได้

บัวสาย (สายบัว)

Water Lily Stem (Nymphaea lotus)

ก้านดอกสายบัวอุ้มน้ำ รสจืดกรอบหวานอ่อนๆ นิยมนำมาทำต้มกะทิสายบัวปลาทูสดรสกลมกล่อม

รสจืดกรอบ ส่วนที่กิน: ก้านสายบัว
⭐ ไฟเบอร์กากใยสูง อ่านข้อมูล / View →
