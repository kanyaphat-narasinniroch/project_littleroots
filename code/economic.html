หมวดหมู่: พืชเศรษฐกิจ

ค้นพบ 12 ชนิด / 12 species found
เรียงตาม:

ยางพารา

Para Rubber / Hevea brasiliensis

ผลผลิต: น้ำยางสด ยางแผ่น ยางแปรรูปยานยนต์และถุงมือแพทย์

ยางธรรมชาติ ส่งออกอันดับโลก
อ่านข้อมูล →

ปาล์มน้ำมัน

Oil Palm / Elaeis guineensis

ผลผลิต: ทะลายปาล์มสด สกัดน้ำมันพืช ไบโอดีเซล B100 อาหารและสบู่

พืชน้ำมัน พลังงานชีวภาพ
อ่านข้อมูล →

ข้าวหอมมะลิไทย

Jasmine Rice / Oryza sativa

ผลผลิต: เมล็ดข้าว ข้าวแปรรูปอาหาร ข้าวกล้อง แป้งข้าวเจ้าคุณภาพสูง

ข้าวนาปี สินค้า GI ไทย
อ่านข้อมูล →

อ้อยโรงงาน

Sugarcane / Saccharum officinarum

ผลผลิต: น้ำอ้อย กากน้ำตาล เอทานอล ไฟฟ้าชีวมวล และบรรจุภัณฑ์ชานอ้อย

อุตสาหกรรมน้ำตาล พลังงานสะอาด
อ่านข้อมูล →

มันสำปะหลัง

Cassava / Manihot esculenta

ผลผลิต: มันเส้น มันอัดเม็ด แป้งมันสำปะหลังแปรรูป สารให้ความหวานและเอทานอล

พืชหัว แป้งอุตสาหกรรม
อ่านข้อมูล →

ข้าวโพดเลี้ยงสัตว์

Field Corn / Zea mays

ผลผลิต: เมล็ดข้าวโพด อาหารสัตว์ อุตสาหกรรมแป้ง และน้ำมันข้าวโพด

วัตถุดิบอาหารสัตว์ เกษตรอุตสาหกรรม
อ่านข้อมูล →

กาแฟโรบัสต้า

Robusta Coffee / Coffea canephora

ผลผลิต: เมล็ดกาแฟสด แปรรูปกาแฟสำเร็จรูป สารสกัดคาเฟอีน ปลูกมากภาคใต้

เครื่องดื่ม เศรษฐกิจภาคใต้
อ่านข้อมูล →

โกโก้ไทย

Thai Cacao / Theobroma cacao

ผลผลิต: เมล็ดโกโก้หมัก ผงโกโก้ เนยโกโก้ ช็อกโกแลตพรีเมียมคราฟต์ไทย

พืชดาวรุ่ง Craft Chocolate
อ่านข้อมูล →

มะพร้าวน้ำหอม

Aromatic Coconut / Cocos nucifera

ผลผลิต: น้ำมะพร้าวสด วุ้นมะพร้าว แปรรูปส่งออก ตลาดโลกนิยมสูง

สินค้า GI เอกลักษณ์ไทย
อ่านข้อมูล →

ไผ่ตง

Sweet Bamboo / Dendrocalamus asper

ผลผลิต: เนื้อไม้แปรรูป ถ่านไผ่คุณภาพสูง หน่อไม้กระป๋อง เครื่องจักสาน

ไม้โตเร็ว งานก่อสร้างและอาหาร
อ่านข้อมูล →

ป่านศรนารายณ์

Sisal / Agave sisalana

ผลผลิต: เส้นใยเหนียวทน เชือก กระเป๋า หมวก พรมธรรมชาติ หัตถกรรมสร้างมูลค่า

เส้นใยธรรมชาติ งานจักสาน
อ่านข้อมูล →

สับปะรดโรงงาน

Pineapple / Ananas comosus

ผลผลิต: สับปะรดกระป๋อง น้ำผลไม้เข้มข้น เส้นใยใบสับปะรดแปรรูปสิ่งทอ

ผลไม้แปรรูป สับปะรดกระป๋อง
อ่านข้อมูล →
